Política de Privacidade

Última atualização: 22 de setembro de 2026

1. Quem somos

Este site é operado por Gabriel Fernandes, prestador de serviços de criação de sites ("nós"). Esta Política de Privacidade explica como tratamos os dados pessoais de quem visita este site ou envia mensagens através dele, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

2. Quais dados coletamos

Este site não possui cadastro de usuários nem cobra pagamentos diretamente. Os únicos dados pessoais coletados são os que você mesmo fornece de forma voluntária ao preencher o formulário de orçamento, como:

  • Nome da empresa ou negócio;
  • Tipo de site e recursos de interesse selecionados;
  • Informações adicionais que você inclua na mensagem enviada via WhatsApp.

O envio do formulário abre uma conversa diretamente no WhatsApp, com a mensagem pré-preenchida. Não armazenamos essas informações em nenhum banco de dados deste site — a conversa passa a ocorrer no seu próprio aplicativo de WhatsApp.

3. Como usamos os dados

As informações enviadas via WhatsApp são usadas exclusivamente para responder à sua solicitação de orçamento e dar continuidade ao atendimento comercial. Não utilizamos esses dados para fins de marketing não solicitado, nem os compartilhamos com terceiros.

4. Cookies e tecnologias de terceiros

Este site utiliza serviços de terceiros para funcionamento e estilo, como Google Fonts, FontAwesome e Tailwind CSS via CDN. Esses serviços podem registrar dados técnicos padrão de requisição (como endereço IP e user-agent) segundo suas próprias políticas de privacidade. Este site não utiliza cookies próprios de rastreamento.

5. Compartilhamento de dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais. Os dados enviados via formulário ficam disponíveis apenas na conversa de WhatsApp entre você e Gabriel Fernandes.

6. Seus direitos como titular de dados

De acordo com a LGPD, você tem direito a confirmar a existência de tratamento, acessar, corrigir ou solicitar a exclusão dos seus dados pessoais compartilhados conosco. Para exercer qualquer um desses direitos, entre em contato pelo WhatsApp informado neste site.

7. Alterações a esta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir mudanças em nossas práticas. A data da última atualização estará sempre indicada no topo desta página.

8. Contato

Dúvidas sobre esta Política de Privacidade podem ser enviadas pelo WhatsApp: (85) 98531-3082.
